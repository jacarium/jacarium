Task states

State Meaning What it is Effect on CFS
>RRunningExecuting on the CPU, consuming CPU time.Actively scheduled by CFS, the task on the CPU now.
RRunnableReady to run, on the run queue, waiting for its turn.In the run queue, competes for the CPU by vruntime.
SSleepingWaiting for an event (I/O, a timer), not using the CPU.Not on the run queue; ignored by CFS until it wakes.
IIdleAn idle kernel thread.Ignored by CFS until runnable; does not count towards the load average.
DI/O waitWaiting on a resource (usually I/O) and not interruptible, even by a signal: disk I/O, an NFS or network storage stall, a faulty driver, memory pressure with swap.Ignored by CFS until runnable; counts towards the load average.
