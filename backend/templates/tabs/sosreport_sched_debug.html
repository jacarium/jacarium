Task States Explained

State Meaning Description
R Runnable Ready to run, on the runqueue, not currently executing.
>R Running Currently executing on CPU, consuming CPU time.
S Sleeping Waiting for an event (I/O, timer), not using CPU.
I Idle Idle process.
D I/O Wait The process is waiting on a resource (usually I/O) and cannot be interrupted, even by signals.
Common causes:
  • Waiting for disk I/O
  • NFS/network storage stalls
  • Faulty drivers
  • Memory pressure with swap

Impact on CFS

State Effect on CFS
>R Actively scheduled by CFS, currently executing.
R In the runqueue, competes for CPU based on vruntime.
S Not on the runqueue; ignored by CFS until wakeup.
I Ignored by CFS until runnable; can affect load average.
D Ignored by CFS until runnable; can affect load average.
