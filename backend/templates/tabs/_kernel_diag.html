{# The kernel diagnostics tabs (Stack Traces, Hung Tasks, OOM Killer) share one "incident board" look: a summary strip (stat tiles, a tiny events-over- time bar strip, offender chips), a filter row, and a list of collapsible rows, each with a facts list, a monospace stack block and the raw lines. Everything is styled by the kd-* rules below, written on the app's tokens (with fallbacks for the standalone Flask page). The diagnostics frame only has the APP's compiled Tailwind, so a utility class used by a template alone (a four-column grid, a grey background...) does not exist there: that is how the old tabs ended up with overlapping columns. Icons are inline SVG. Severity colours are the Log Viewer's fixed badge colours (red / amber / blue): status colours stay semantic in both themes and always come with a label, never colour alone. Report content is untrusted: the templates render it through Jinja's autoescaping only (nothing marked safe), and the script below never builds HTML from it (it toggles, filters by textContent, copies textContent). #}
